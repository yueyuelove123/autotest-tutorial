    第 1 章 准备环境与 Python 速成¶

    本章目标

    • 装好 Python 和 VS Code，会在命令行里运行命令；
    • 建好工程文件夹和虚拟环境，装好整套教程要用的工具；
    • 掌握本教程用得到的 Python 语法。已经会 Python 的同学可以跳过 1.6 节。

    1.1 安装 Python¶

    1. 打开 https://www.python.org/downloads/windows/，找到 Python 3.13 的最新小版本（比如 3.13.7），下载 Windows installer (64-bit)。
    2. 双击安装，第一个界面最下方一定要勾选 Add python.exe to PATH，然后点 Install Now。

    这个勾决定了你能不能在命令行里直接输入 python。忘了勾的话，重新运行安装程序选 Modify 补上，或者卸载重装。

    1. 装好后按 Win 键，输入 PowerShell 打开它，输入下面两条命令检查：
    > python --version
Python 3.13.7
> pip --version
pip 25.2 from C:\Users\你的用户名\AppData\Local\Programs\Python\Python313\Lib\site-packages\pip (python 3.13)

    能看到版本号就装好了。

    说明

    为什么不装最新的 3.15？ Python 3.15 在 2026 年 10 月 9 日刚发布。性能测试工具 Locust 依赖的 gevent、geventhttpclient 是用 C 语言写的，需要作者为每个 Python 版本单独打好安装包，新版本刚发布时这些安装包往往还没跟上，pip 就会尝试现场编译，没装编译器就会失败。学习阶段选 3.13 或 3.14 最省心。

    坑

    输入 python 弹出了微软应用商店。 这是 Windows 自带的「应用执行别名」在作怪。打开「设置 → 应用 → 高级应用设置 → 应用执行别名」，把 python.exe 和 python3.exe 两个开关关掉，再重新打开 PowerShell。

    1.2 安装 VS Code¶

    写代码需要一个顺手的编辑器，推荐免费的 VS Code：

    1. 到 https://code.visualstudio.com/ 下载安装，安装时把「添加到 PATH」「通过 Code 打开」几个选项都勾上。
    2. 打开 VS Code，点左侧的扩展图标（四个方块），搜索安装：
    3. Python（微软出的，必装）；
    4. Chinese (Simplified) Language Pack（中文界面，可选）。
    5. 用「文件 → 打开文件夹」打开你的工程文件夹；用菜单「终端 → 新建终端」（快捷键 Ctrl+`）在 VS Code 下方打开命令行，后面的命令都可以在这里输入。

    说明

    以后装了新工具要重开 VS Code。 后面还会装 Node.js、Git 这些工具，安装程序会把它们加进系统的 PATH（系统按它去找命令）。VS Code 里的终端用的是 VS Code 启动那一刻的 PATH，装完新工具只新开一个终端是不够的，要把 VS Code 整个关掉再打开，否则会提示「不是内部或外部命令」。单独打开的 PowerShell 窗口则是新开一个就行。

    1.3 命令行入门¶

    命令行（也叫终端）就是用打字代替鼠标来操作电脑的窗口。自动化测试的工具基本都在命令行里运行，下面几条命令够用了：

    命令 作用 例子
    pwd 显示当前在哪个文件夹 pwd
    cd 路径 进入某个文件夹 cd D:\work，cd ..（回到上一级）
    ls 列出当前文件夹里的内容 ls
    mkdir 名字 新建文件夹 mkdir reports
    python 文件名 运行一个 Python 文件 python hello.py
    cls 清屏 cls

    几个必须记住的操作：

    • Ctrl + C：停止正在运行的程序（比如停掉练习网站、停掉压测）；
    • ↑ 键：翻出上一条命令，不用重新打；
    • Tab 键：自动补全文件名和文件夹名，打几个字按一下 Tab；
    • 路径：D:\work\autotest-demo 这样从盘符写起的叫绝对路径；tests\api 这样从当前文件夹往下写的叫相对路径。命令里的相对路径都是相对于「当前所在的文件夹」，所以运行命令前先确认自己在工程根目录。

    1.4 建工程和虚拟环境¶

    1.4.1 新建工程文件夹¶

    > mkdir D:\work\autotest-demo
> cd D:\work\autotest-demo

    电脑上没有 D 盘的，换成 C:\work\autotest-demo，后面所有出现 D:\work 的地方都照此替换。

    路径里尽量只用英文、数字和短横线，不要有中文和空格。大部分工具能处理中文路径，但个别工具会因为编码问题出错，从一开始就避开最省事。

    1.4.2 为什么要虚拟环境¶

    pip 装的包默认装在 Python 自己的目录里，所有工程共用一份。工程一多就会打架：A 工程要 pytest 8，B 工程要 pytest 9，只能留一个。

    虚拟环境就是给每个工程单独准备一份「Python + 包」，装什么、装哪个版本都只影响这个工程。它就是工程目录下的一个 .venv 文件夹，删掉重建也没关系。

    1.4.3 创建并激活¶

    > python -m venv .venv
> .venv\Scripts\Activate.ps1
(.venv) >

    命令行开头出现 (.venv)，说明虚拟环境已经激活，之后的 python、pip 用的都是这个工程自己的。每次新开命令行窗口都要重新激活一次。

    • Mac / Linux 的激活命令是 source .venv/bin/activate；
    • 退出虚拟环境输入 deactivate；
    • VS Code 里按 Ctrl+Shift+P，输入 Python: Select Interpreter，选 .venv 里的那个 Python，以后新开的终端会自动激活。

    坑

    执行 Activate.ps1 报错「无法加载文件……因为在此系统上禁止运行脚本」。 PowerShell 默认不允许运行脚本，执行一次下面的命令放开当前用户的限制（提示时输入 Y）：

    > Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

    1.5 安装依赖¶

    在工程根目录新建一个文本文件 requirements.txt，内容如下。它是这个工程的「依赖清单」，写清楚要哪些包、哪个版本，换台电脑一条命令就能装出一模一样的环境：

    # 练习网站（被测系统）
fastapi==0.159.1
uvicorn==0.54.0

# 接口自动化
requests==2.34.2
pytest==9.1.1
PyYAML==6.0.3
jsonschema==4.26.0

# UI 自动化
playwright==1.64.0
pytest-playwright==0.10.0

# 报告与并行
allure-pytest==2.16.2
pytest-xdist==3.8.0

# 性能测试
locust==2.47.0

    确认命令行开头有 (.venv)，然后安装：

    (.venv) > pip install -r requirements.txt

    下载慢或者超时，可以换成国内的镜像源：

    (.venv) > pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

    想以后一直用镜像，执行一次 pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple 即可。

    装完检查一下：

    (.venv) > pytest --version
pytest 9.1.1
(.venv) > locust --version
locust 2.47.0 from D:\work\autotest-demo\.venv\Lib\site-packages\locust (Python 3.13.7)
(.venv) > playwright --version
Version 1.64.0

    浏览器¶

    UI 自动化需要一个浏览器。本教程直接用你电脑上装好的 Google Chrome，不用另外下载。如果没装 Chrome，二选一：

    • 用 Windows 自带的 Edge：后面所有指定 chrome 的地方换成 msedge；
    • 让 Playwright 下载它自带的浏览器：playwright install chromium（约 150 MB，公司网络可能下载不了），然后把后面指定 chrome 的地方都去掉。

    后面指定 chrome 的地方有三处：脚本里的 channel="chrome"（第 8 章）、录制命令里的 --channel chrome（第 8 章）、pytest.ini 里的 --browser-channel=chrome（第 8、11 章）。另外，第 11 章提到的 Firefox、WebKit 两种内核，要先执行 playwright install firefox webkit 下载才能用。

    autotest-demo/
├─ .venv/              虚拟环境（自动生成，不用管）
└─ requirements.txt    依赖清单

    1.6 Python 速成¶

    这一节只讲本教程用得到的语法。建议在工程里新建一个 scratch 文件夹专门放练习代码，每个例子存成一个 .py 文件，用 python scratch\文件名.py 运行，看输出和教程里是否一致。

    1.6.1 第一个程序¶

    新建 scratch/hello.py：

    print("你好，自动化测试")
print(1 + 2)

    > python scratch\hello.py
你好，自动化测试
3

    print 把内容打印到屏幕上，是最常用的调试手段：不知道某个值是什么，就把它打印出来看看。# 后面是注释，程序运行时会忽略，用来写给人看的说明。

    1.6.2 变量和数据类型¶

    变量就是给一个值起名字，后面用名字来指代它：

    username = "alice"      # 字符串 str：用引号包起来的文字
age = 18                # 整数 int
price = 2.5             # 小数 float
is_vip = True           # 布尔值 bool：只有 True 和 False 两个值
token = None            # None 表示「没有值」

print(type(username), type(age), type(price), type(is_vip), type(token))
print(price * 3)

    输出：

    <class 'str'> <class 'int'> <class 'float'> <class 'bool'> <class 'NoneType'>
7.5

    1.6.3 字符串¶

    name = "中性笔"
count = 3
text = f"{name} 买了 {count} 件"        # f-string：在花括号里直接放变量
print(text)
print(len(text))                        # 长度
print("笔" in name)                     # 是否包含
print("  alice  ".strip())              # 去掉两头的空格
print("a,b,c".split(","))               # 按逗号切开
print(f"金额：{2.5 * 3:.2f} 元")         # :.2f 表示保留两位小数

    输出：

    中性笔 买了 3 件
10
True
alice
['a', 'b', 'c']
金额：7.50 元

    1.6.4 列表¶

    列表用方括号，按顺序存放一组值：

    names = ["蓝牙耳机", "机械键盘", "无线鼠标"]
print(names[0])          # 第一个，下标从 0 开始
print(names[-1])         # 最后一个
print(names[0:2])        # 切片：第 0 个到第 2 个之前
names.append("台灯")      # 在末尾添加
print(len(names), names)

for n in names:          # 逐个取出来
    print("商品：", n)

lengths = [len(n) for n in names]   # 列表推导：把每个元素加工一下，生成新列表
print(lengths)

    输出：

    蓝牙耳机
无线鼠标
['蓝牙耳机', '机械键盘']
4 ['蓝牙耳机', '机械键盘', '无线鼠标', '台灯']
商品： 蓝牙耳机
商品： 机械键盘
商品： 无线鼠标
商品： 台灯
[4, 4, 4, 2]

    注意 for 下面的那行前面有 4 个空格。Python 用缩进表示代码的层级，缩进不对程序就会报错或者逻辑出错。VS Code 里按 Tab 会自动输入 4 个空格。

    1.6.5 字典（最重要）¶

    字典用花括号，存放「键: 值」对。接口返回的 JSON 数据转成 Python 之后就是字典和列表的组合，所以这一节一定要掌握：

    resp = {
    "code": 0,
    "msg": "ok",
    "data": {
        "total": 2,
        "items": [
            {"id": 1, "name": "蓝牙耳机", "price": 199.0},
            {"id": 2, "name": "头戴式耳机", "price": 399.0},
        ],
    },
}

print(resp["code"])                         # 按键取值
print(resp["data"]["items"][0]["name"])     # 一层层往下取
print(resp.get("trace_id"))                 # 键不存在时 get 返回 None，[] 会报错
print(resp.get("trace_id", "没有"))          # 也可以指定默认值

resp["msg"] = "成功"                         # 修改
for key, value in resp["data"]["items"][1].items():   # 遍历
    print(key, "=", value)

prices = [item["price"] for item in resp["data"]["items"]]
print("总价：", sum(prices))

    输出：

    0
蓝牙耳机
None
没有
id = 2
name = 头戴式耳机
price = 399.0
总价： 598.0

    1.6.6 条件和循环¶

    balance = 100.0
amount = 120.0

if amount <= 0:
    print("金额不对")
elif balance >= amount:
    print("可以支付")
else:
    print(f"余额不足，还差 {amount - balance:.2f} 元")

for i in range(3):          # range(3) 依次给出 0、1、2
    print("第", i + 1, "次")

n = 0
while n < 5:                # 条件成立就一直循环
    n += 1                  # 等同于 n = n + 1
    if n == 2:
        continue            # 跳过本次，进入下一次
    if n == 4:
        break               # 直接结束循环
    print("n =", n)

    输出：

    余额不足，还差 20.00 元
第 1 次
第 2 次
第 3 次
n = 1
n = 3

    比较用 ==（等于）、!=（不等于）、>、>=、<、<=；组合条件用 and、or、not。注意 = 是赋值，== 才是比较。

    1.6.7 函数¶

    把一段经常要用的代码包起来、起个名字，就是函数：

    def calc_amount(price, quantity=1, discount=0):
    """计算订单金额：单价 × 数量 - 优惠。三个引号里的文字是函数说明。"""
    return round(price * quantity - discount, 2)


print(calc_amount(2.5))                       # 只传 price，其余用默认值
print(calc_amount(2.5, 3))                    # 按顺序传
print(calc_amount(199, quantity=2, discount=20))   # 按名字传，更清楚

    输出：

    2.5
7.5
378

    return 把结果交还给调用的地方。函数可以有参数，也可以给参数设默认值。

    1.6.8 模块和导入¶

    一个 .py 文件就是一个模块，别的文件可以 import 它来用里面的东西。新建 scratch/money.py：

    def yuan(cents):
    return round(cents / 100, 2)

    再新建 scratch/use_money.py，和前面一样在工程根目录用 python scratch\use_money.py 运行：

    import json                      # Python 自带的模块
from money import yuan           # 自己写的模块：从 money.py 里导入 yuan 函数

print(yuan(250))
print(json.dumps({"name": "中性笔"}, ensure_ascii=False))

    输出：

    2.5
{"name": "中性笔"}

    运行一个脚本时，Python 会自动到这个脚本所在的文件夹里找要导入的模块，所以 money.py 和 use_money.py 放在同一个文件夹里就能导入。pip 装的包也是这样用的，比如 import requests、from playwright.sync_api import expect。导入报 ModuleNotFoundError：导入的是 pip 装的包，八成是虚拟环境没激活或者包没装；导入的是自己写的模块，检查它和运行的脚本是不是在同一个文件夹里、名字有没有拼错。

    1.6.9 类和对象¶

    类是「一类东西」的模板，对象是按模板造出来的具体一个。后面的接口客户端、页面对象都是类，先看个例子：

    class Account:
    def __init__(self, username, balance):   # 创建对象时自动执行，self 指这个对象自己
        self.username = username             # 属性：对象身上的数据
        self.balance = balance

    def pay(self, amount):                   # 方法：对象能做的事
        if amount > self.balance:
            return False
        self.balance -= amount
        return True


alice = Account("alice", 100)
print(alice.pay(30), alice.balance)
print(alice.pay(100), alice.balance)


class VipAccount(Account):                   # 继承：VipAccount 自动拥有 Account 的一切
    def pay(self, amount):                   # 再改写其中一个方法：会员打九折
        return super().pay(amount * 0.9)


bob = VipAccount("bob", 100)
print(bob.pay(100), bob.balance)

    输出：

    True 70
False 70
True 10.0

    1.6.10 异常和断言¶

    程序出错时会抛出异常，不处理就会中断。try/except 可以把异常「捕获」下来：

    data = {"code": 0}
try:
    print(data["token"])
except KeyError as e:
    print("没有这个键：", e)
finally:
    print("不管有没有出错，finally 都会执行，常用来做清理")

balance = 70
assert balance == 70, "余额应该是 70"     # 条件成立，什么都不发生
try:
    assert balance == 100, f"余额应该是 100，实际是 {balance}"
except AssertionError as e:
    print("断言失败：", e)

    输出：

    没有这个键： 'token'
不管有没有出错，finally 都会执行，常用来做清理
断言失败： 余额应该是 100，实际是 70

    assert 是自动化测试的核心：assert 条件, 失败时的说明，条件成立就继续，不成立就抛出 AssertionError，测试框架看到它就把这条用例记为失败。

    1.6.11 文件读写与 with¶

    with open("note.txt", "w", encoding="utf-8") as f:     # w：写入（会覆盖原内容）
    f.write("第一行\n第二行\n")

with open("note.txt", encoding="utf-8") as f:          # 默认是读
    for line in f:
        print(line.strip())

    输出：

    第一行
第二行

    with 保证用完之后自动关闭文件。读写文件永远带上 encoding="utf-8"，否则 Windows 上默认按 GBK 编码处理，遇到中文就会乱码或报错。

    1.6.12 JSON 和字典互相转换¶

    接口传输的数据格式大多是 JSON。它长得和 Python 字典几乎一样，但它是一段文字：

    import json

text = '{"username": "alice", "vip": true, "coupon": null}'
data = json.loads(text)                  # JSON 文字 → 字典
print(data, type(data))

back = json.dumps(data, ensure_ascii=False, indent=2)   # 字典 → JSON 文字
print(back)

    输出：

    {'username': 'alice', 'vip': True, 'coupon': None} <class 'dict'>
{
  "username": "alice",
  "vip": true,
  "coupon": null
}

    注意 JSON 里的 true、false、null 对应 Python 的 True、False、None。ensure_ascii=False 让中文原样输出，indent=2 让结果分行缩进、便于阅读。

    1.6.13 认识装饰器的写法¶

    后面会大量见到写在函数上面、以 @ 开头的一行，比如：

    @pytest.fixture
def token():
    ...

    这叫装饰器，作用是给函数「加点功能」或者「贴个标签」。现阶段不用会写，知道 @pytest.fixture 的意思是「把下面这个函数登记成 pytest 的夹具」就够了，后面用到时再细讲。

    1.7 常见的坑¶

    现象 原因与解决
    python 不是内部或外部命令 安装时没勾 Add python.exe to PATH，重新安装勾上
    输入 python 打开了应用商店 关掉「应用执行别名」里的 python.exe，见 1.1
    ModuleNotFoundError: No module named 'xxx' 虚拟环境没激活，或者包没装进这个虚拟环境
    IndentationError 缩进不对，检查是不是空格和 Tab 混用了
    KeyError: 'xxx' 字典里没有这个键，先 print 出来看看实际的结构
    读文件中文乱码、UnicodeDecodeError 打开文件时没写 encoding="utf-8"
    SyntaxError 语法错误，常见的是括号、引号没配对，或者用了中文标点
